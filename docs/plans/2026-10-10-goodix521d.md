# GF5298 free-driver integration plan

Base: official libfprint master `6f9479c3d55f847c1b3769f28ceb99227f9858cf`.
Branch: `feat/goodix-521d-openchicago`.

1. Preserve the authenticated working transport with portable negative tests; remove image-device and key-write coupling.
2. Port bounded factory/profile decoding and the validated twelve-state paired background sequence. Keep raw capture in memory, exact length/CRC and command association checks.
3. Add explicit GF5298 profile 17 preprocessing to the pinned MR Chicago code, retaining profile 24 behavior and all license notices. Test profile separation and frozen offline comparisons.
4. Add an FpDevice driver with read-only provisioned inputs, asynchronous open/enroll/verify/identify/close, bounded operations and cancellation. Enforce independent contacts and natural enrollment completion.
5. Wrap native matcher templates in a strict versioned sensor/config/profile envelope. Test malformed input, incompatible profiles, completed-enrollment export and fresh-session import.
6. Build the selected driver and all upstream drivers; run portable/unit/lifecycle tests and sanitizers where supported. Add exact-commit Arch packaging and installation-free instructions.
7. Independently review source, license attribution, privacy, lifecycle and template persistence. Publish the feature branch and an experimental draft PR, preserving the working v3 reference.

Acceptance does not follow from compilation alone. Physical enrollment, genuine/wrong-finger verification, cancellation, unplug/reopen and fprintd restart must be tested locally before recommending authentication use. No partial enrollment, threshold tuning on holdouts, firmware/key writes, service changes or system installation are part of this implementation.
